# API 速率限制与配额

接口返回 429 Too Many Requests 表示当前账号在窗口期内超过了配额。

- 默认限额按账号维度计算，不是按 IP。
- 企业版在合同里约定的 QPS 需要单独开通，控制台里显示的仍然是默认档位。
- 短时突发可以用指数退避重试：间隔从 200 毫秒开始翻倍，最多重试五次。
- 需要提高配额，提交工单时附上账号 ID、峰值 QPS 和业务用途，我们会在两个工作日内调整。

排查顺序：先确认请求头里的 X-RateLimit-Remaining 是否为 0，再看是否多个服务共用同一个 API Key。多服务共用是 429 最常见的原因，建议按服务拆分 Key。

配额调整生效后，历史 429 不会自动重放，需要业务侧重跑失败批次。
